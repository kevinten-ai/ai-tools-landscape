# AI Tools Landscape 2025-2026

> 各领域 AI 工具王者全景调研 —— 覆盖 30+ 领域，逐月追踪，持续更新

## 项目简介

本项目系统梳理 2025-2026 年 AI 工具在各主要领域的竞争格局，包括：

- **谁是王者** —— 每个领域的市场领导者
- **谁在挑战** —— 有竞争力的替代方案
- **如何演进** —— 月度能力变化追踪
- **如何选择** —— 不同场景下的最佳选择建议

| 写作/对话 | **ChatGPT** | 3亿周活，综合生态最强 |
| 图像生成 | **Midjourney** | 美学质量全面领先 |
