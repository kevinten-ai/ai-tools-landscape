## 2025年9月 — CC 2.0 发布，转折点开始

| | Claude Code | Cursor |
|---|---|---|
| **亮点** | **Claude Code 2.0** + **Sonnet 4.5**（SWE-bench 77.2%）：原生 VS Code 扩展、Checkpoints（代码快照回退）、全新终端 UX、Agent SDK；Sonnet 4.5 能持续自主编码 30+ 小时 | v1.5 Linear 集成；v1.7：Agent Autocomplete、Hooks beta、Team Rules、图片支持 |

## 2025年10月

| | Claude Code | Cursor |
|---|---|---|
| **亮点** | Agent Skills 系统（动态加载指令集）、Thinking block 清理优化 | **Cursor 2.0**（10月29日）：Composer 模型（4x 快）、多 Agent 界面（最多8个并行）、内置浏览器、沙盒终端、语音模式、**Cloud Agents**（远程执行） |
| **评价** | CC 在可扩展性上发力 | Cursor 最大版本更新，UI/多 Agent 体验领先 |

---

## 2025年11月 — 关键转折

| | Claude Code | Cursor |
|---|---|---|
| **亮点** | **Opus 4.5 发布（11月24日）**——"世界最强编码/Agent/计算机使用模型"；定价下调（$5/$25 per M tokens）；**CC 达到 $10亿年化营收**（GA 仅6个月，比 ChatGPT 还快） | Plan Mode UI 增强、多 Agent 优化 |
| **评价** | **模型质量碾压** + 商业成功验证，CC 在核心能力上全面超越 | 功能面上仍有优势（多 Agent GUI），但底层模型差距明显 |

### 9-11月三连击总结

1. **9月**：CC 2.0 + Sonnet 4.5（补齐 IDE 短板 + 模型升级）
2. **10月**：Skills 系统（可扩展性）
3. **11月**：Opus 4.5（模型质量封王）+ $10亿营收里程碑

## 综合对比矩阵

| 维度 | Claude Code 优势 | Cursor 优势 |
|---|---|---|
| **模型质量** | Opus 4.5/4.6 编码能力最强，token 消耗仅 Cursor 的 1/5.5 | Composer 模型速度快，实时 RL 训练 |
| **自主能力** | 30+ 小时持续自主编码；Agent Teams | 8个并行 Cloud Agents；远程执行 |
| **IDE 体验** | 终端优先 + VS Code 扩展（9月补齐） | 原生 VS Code fork，GUI 体验更丝滑 |
| **可视化** | 终端为主，Cowork 是新尝试 | 内置浏览器、可视化编辑器、Debug Mode |
| **可扩展** | MCP + Hooks + Skills + Agent SDK | MCP + Hooks + Automations + MCP Apps |
| **商业** | $25亿 ARR，开发者满意度 46% | $20亿 ARR，满意度 19% |

## 最佳实践建议

**当前主流开发者的最佳组合**：
- **重活 / 复杂重构** → Claude Code
- **日常编辑 / 可视化** → Cursor
- **GitHub 工作流** → Copilot
