# 邮件 AI

> AI 邮件处理领域的工具对比

---

## 王者：Superhuman

- **定价**: $25-30/月
- **核心优势**:
  - **速度极致** —— 100ms 响应，键盘快捷键驱动
  - AI 写信（一键草拟回复）
  - AI 优先级分类（Split Inbox）
  - 日程自动检测
  - Read Status 追踪
  - 精美设计体验
- **劣势**: 价格高，仅支持 Gmail 和 Outlook

---

## 挑战者

### Microsoft Copilot (Outlook)
- **定价**: M365 Copilot $30/用户/月
- **核心优势**:
  - Microsoft 生态深度集成
  - AI 摘要邮件线程
  - 自动草拟回复
  - Teams + Calendar 联动
- **适合**: Microsoft 365 企业用户

### Spark AI
- **定价**: Free / Premium $5/月
- **核心优势**: 价格亲民，AI 写信，团队邮件协作
- **适合**: 预算有限的团队

### Shortwave
- **定价**: Free / Pro $9/月
- **核心优势**: AI 邮件搜索和摘要，简洁 UI
- **适合**: Gmail 用户

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 速度 + 体验最佳 | **Superhuman** |
| Microsoft 生态 | Copilot (Outlook) |
| 性价比 | Spark AI |
| Gmail 增强 | Shortwave |
