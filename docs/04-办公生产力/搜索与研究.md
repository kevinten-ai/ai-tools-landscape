# 搜索与研究 AI

> AI 搜索和研究领域的工具对比

---

## 王者：Perplexity AI

- **月活**: 1500万+
- **定价**: Free / Pro $20/月 / Enterprise $40/用户/月
- **核心优势**:
  - **引用透明度第一** —— 每个答案标注来源
  - 实时网络搜索 + AI 总结
  - 多模型可选（Claude、GPT 等）
  - Focus 模式（学术、Reddit、YouTube 等）
  - Collections 协作研究
  - API 支持
- **劣势**: 深度推理不如直接用 Claude/ChatGPT

---

## 挑战者

### Google AI Overviews
- **定价**: 免费（Google Search 内置）
- **核心优势**:
  - **覆盖面最广** —— Google 搜索默认 AI 摘要
  - 无需切换工具
  - Google 知识图谱加持
- **劣势**: 引用不如 Perplexity 详细

### SearchGPT / ChatGPT Search
- **定价**: ChatGPT Plus $20/月
- **核心优势**: ChatGPT 生态集成，对话式搜索，可继续深入
- **适合**: ChatGPT 用户

### Exa
- **定价**: API 按查询计费
- **核心优势**: 语义搜索 API，适合开发者集成
- **适合**: 构建 AI 应用的开发者

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 日常研究/带引用 | **Perplexity** |
| 无需切换工具 | Google AI Overviews |
| 对话式深入 | ChatGPT Search |
| 开发者 API | Exa |
