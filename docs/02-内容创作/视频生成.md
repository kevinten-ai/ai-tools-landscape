# 视频生成 AI

> AI 视频生成领域的工具对比（Sora 已死，群雄割据）

---

## 重大事件：Sora 独立应用已于 2026年3月关闭

OpenAI 将 Sora 视频生成功能并入 ChatGPT，不再作为独立产品运营。

---

## 王者：Veo 3.1 (Google DeepMind)

- **定价**: Gemini Advanced $20/月 / API 按秒计费
- **核心优势**:
  - **画质 + 音频同步最强** —— 原生生成配套音效和对话
  - 分辨率高（1080p+）
  - 物理模拟准确
  - 与 Gemini 生态深度集成
- **劣势**: API 价格较高

---

## 强力挑战者

### Runway Gen-4
- **定价**: Free / Standard $15 / Pro $35 / Unlimited $95
- **核心优势**:
  - **创意控制最强** —— 运动控制、摄像机路径、风格参考
  - 视频编辑工作流成熟
  - 影视行业采用度高
- **适合**: 创意专业人士、影视制作

### Kling 2.0 (快手)
- **定价**: 免费 / Pro 按次
- **核心优势**:
  - **性价比极高** —— 免费额度慷慨
  - 中文提示词理解好
  - 长视频生成
- **适合**: 预算有限、中文内容创作

### Pika
- **定价**: Free / Standard $10 / Pro $35
- **核心优势**: 易用性好，适合短视频和社交媒体内容
- **适合**: 社交媒体创作者

### HaiLuo / MiniMax
- **定价**: 免费 / Pro 按次
- **核心优势**: 人物一致性好，面部表情自然
- **适合**: 人物视频、数字人

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 最高画质 + 音频 | **Veo 3.1** |
| 创意控制/影视 | Runway Gen-4 |
| 性价比/免费 | Kling 2.0 |
| 简单易用 | Pika |
| 人物视频 | HaiLuo |
