# 图像生成 AI

> AI 图像生成领域的工具对比

---

## 王者：Midjourney

- **当前版本**: v7
- **定价**: Basic $10 / Standard $30 / Pro $60 / Mega $120
- **核心优势**:
  - **美学质量全面领先** —— 构图、光影、细节均为最佳
  - 风格多样性强
  - 社区生态活跃（Discord 原生）
  - 支持网页编辑器
- **劣势**: 无 API（2026年初仍未开放），不适合自动化流程

---

## 强力挑战者

### DALL-E 3 (OpenAI)
- **定价**: 内置于 ChatGPT（Plus $20/月）
- **核心优势**:
  - ChatGPT 原生集成，对话式修改
  - 文字渲染能力最强
  - GPT-5 理解提示词更准确
- **劣势**: 美学质量不及 Midjourney
- **适合**: ChatGPT 用户、需要精确文字渲染

### Flux 1.1 (Black Forest Labs)
- **定价**: 开源（本地免费）/ 云端按次计费
- **核心优势**:
  - **开源最强** —— 本地部署无限制
  - 速度快，质量接近 Midjourney
  - 支持 ControlNet 等高级控制
- **适合**: 开发者、需要本地部署、批量生成

### Ideogram 3
- **定价**: Free / Plus $8 / Pro $20
- **核心优势**:
  - 文字渲染准确（Logo、海报）
  - 设计感强
  - 价格亲民
- **适合**: 设计师、Logo/海报制作

### Stable Diffusion (Stability AI)
- **定价**: 开源免费
- **核心优势**: 完全开源，插件生态最丰富（LoRA、ControlNet）
- **劣势**: 需要一定技术门槛
- **适合**: 技术用户、需要精细控制

### Google Imagen 3
- **定价**: 内置于 Gemini
- **核心优势**: 真实感强，Google 生态集成
- **适合**: Google 用户

## 选择建议

| 需求 | 推荐 |
|------|------|
| 最高美学质量 | **Midjourney** |
| 对话式修改 | DALL-E 3 (ChatGPT) |
| 开源/本地部署 | Flux / Stable Diffusion |
| 文字/Logo 设计 | Ideogram 3 |
| 预算最低 | Stable Diffusion（免费） |
