# 翻译 AI

> AI 翻译领域的工具对比

---

## 王者：DeepL

- **定价**: Free / Starter $9 / Advanced $29 / Ultimate $60 / API 按字符
- **核心优势**:
  - **翻译质量碾压**，尤其欧洲语言
  - 语境理解更自然
  - 专业术语处理准确
  - 文档翻译（PDF、Word、PPT）
  - 企业级数据安全（欧盟数据中心）
- **劣势**: 支持语言数量有限（33 种），亚洲语言不如欧洲语言好

---

## 强力挑战者

### Google Translate
- **定价**: Free / Cloud Translation API 按字符计费
- **核心优势**:
  - **243 种语言** —— 覆盖面无人能敌
  - 实时摄像头翻译
  - 离线翻译包
  - 与 Chrome、Android 深度集成
- **适合**: 小众语言、日常快速翻译

### Claude / ChatGPT 翻译
- **核心优势**: 上下文理解最强，可以处理复杂语境、文化差异
- **劣势**: 非专用翻译工具，需要额外提示
- **适合**: 需要深度理解语境的翻译（文学、营销文案）

### 百度翻译 / 有道翻译
- **核心优势**: 中文相关翻译最好
- **适合**: 中英互译

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 翻译质量最高 | **DeepL** |
| 语言覆盖最广 | Google Translate |
| 文学/营销翻译 | Claude |
| 中英互译 | DeepL / 百度翻译 |
| 文档批量翻译 | DeepL |
