# 语音与 TTS (Text-to-Speech) AI

> AI 语音合成领域的工具对比

---

## 王者：ElevenLabs

- **定价**: Free / Starter $5 / Creator $22 / Pro $99 / Enterprise 定制
- **核心优势**:
  - **英语品质最佳** —— 自然度、情感表达领先
  - 语音克隆（仅需几秒样本）
  - 多语言支持（29+ 语言）
  - API 成熟，开发者友好
  - 配音、有声书工作流
- **劣势**: 价格较高，中文效果一般

---

## 强力挑战者

### Fish Audio
- **定价**: 约为 ElevenLabs 的 **1/5**
- **核心优势**:
  - **TTS 盲测排名第一**
  - **中文效果更好**
  - 性价比极高
  - 语音克隆质量高
- **适合**: 中文内容、预算敏感、大批量生成
- **评价**: 2025-2026 最大黑马

### OpenAI TTS
- **定价**: 内置于 ChatGPT / API 按字符计费
- **核心优势**: ChatGPT 生态集成，实时语音对话（Advanced Voice）
- **适合**: ChatGPT 用户

### Microsoft Azure TTS
- **定价**: 免费层 + 按字符计费
- **核心优势**: 企业级稳定性，400+ 声音，SSML 精细控制
- **适合**: 企业级应用

### Google Cloud TTS
- **定价**: 免费层 + 按字符计费
- **核心优势**: WaveNet 声音自然，Google 生态集成
- **适合**: GCP 用户

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 英语最高品质 | **ElevenLabs** |
| 中文 + 性价比 | **Fish Audio** |
| ChatGPT 集成 | OpenAI TTS |
| 企业级 | Azure TTS |
| 大批量/预算有限 | Fish Audio |
