# UI/UX 设计 AI

> AI UI/UX 设计领域的工具对比

---

## 王者：Figma AI

- **定价**: Free / Professional $15/月 / Organization $45/月 / Enterprise $75/月
- **核心优势**:
  - **行业标准设计工具** + AI 增强
  - AI 自动生成/修改设计稿
  - 实时团队协作
  - Dev Mode 开发者交付
  - 插件生态丰富
- **劣势**: AI 功能仍在迭代，不如专用 AI 工具生成速度快

---

## 挑战者

### v0 (Vercel)
- **定价**: Free / Premium $20/月
- **核心优势**:
  - **前端代码生成最强** —— 描述 UI → 生成 React/Next.js 代码
  - shadcn/ui + Tailwind CSS 原生
  - 可直接部署到 Vercel
- **适合**: 前端开发者、快速原型

### Galileo AI
- **定价**: Beta / 邀请制
- **核心优势**: 高保真 UI 设计自动生成
- **适合**: 快速生成设计概念

### Uizard
- **定价**: Free / Pro $19/月
- **核心优势**: 手绘草图 → 设计稿，适合非设计师
- **适合**: 产品经理快速原型

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 专业 UI 设计 | **Figma AI** |
| 生成前端代码 | **v0** |
| 快速概念验证 | Galileo AI |
| 草图转设计 | Uizard |
