# 3D 建模 AI

> AI 3D 建模领域的工具对比

---

## 王者：Meshy

- **定价**: Free / Pro $20/月 / Max $100/月
- **核心优势**:
  - **图片/文本 → 3D 最成熟** —— 质量、速度、易用性均衡
  - 支持 PBR 材质和纹理
  - 多种导出格式（GLB、FBX、OBJ、STL）
  - API 支持自动化流程
  - 3D 打印友好
- **劣势**: 复杂模型细节仍需手动调整

---

## 挑战者

### Tripo
- **定价**: Free / Pro 按次
- **核心优势**:
  - **速度最快** —— 几秒生成 3D 模型
  - 支持多视角输入
- **适合**: 快速原型、游戏资产

### Rodin Gen-2 (Hyper)
- **定价**: 按次计费
- **核心优势**:
  - **质量最高** —— 细节丰富
  - 支持精细的材质控制
- **适合**: 高质量3D资产制作

### OpenAI Shap-E
- **定价**: 开源免费
- **核心优势**: 开源，可本地部署
- **适合**: 研究、开发者

---

## 选择建议

| 需求 | 推荐 |
|------|------|
| 综合最佳 | **Meshy** |
| 速度优先 | Tripo |
| 质量优先 | Rodin Gen-2 |
| 3D 打印 | Meshy（STL 导出） |
| 开源/免费 | Shap-E |
