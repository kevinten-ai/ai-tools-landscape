# 编程工具全景：2026年 AI 编程工具竞争格局

> 覆盖 IDE、CLI、自主代理等所有 AI 编程工具

---

## 竞争力分层

### 第一梯队：正面硬刚

#### 1. Claude Code (Anthropic)
- **类型**: CLI + VS Code 扩展
- **模型**: Opus 4.6 / Sonnet 4.6（1M 上下文）
- **定价**: Max $100-200/月
- **杀手锏**: 模型质量最强，30+ 小时自主编码，Agent SDK
- **规模**: $25亿+ ARR，开发者满意度 46%

#### 2. Cursor (Anysphere)
- **类型**: AI 原生 IDE（VS Code fork）
- **模型**: 多模型路由（Claude / GPT / Gemini）
- **定价**: Free / Pro $20 / Ultra $200
- **杀手锏**: GUI 体验最佳，Supermaven Tab 补全，8个并行 Cloud Agent
- **规模**: ~$20亿 ARR，36万付费客户

#### 3. GitHub Copilot (Microsoft)
- **类型**: IDE 扩展 + Coding Agent
- **模型**: Claude Opus 4 / GPT-5 / o3（Pro+ 全家桶）
- **定价**: Free / Pro $10 / Pro+ $39 / Business $19
- **杀手锏**: 市场份额最大（~37%），GitHub 无缝集成，Coding Agent 自主接 Issue
- **规模**: 最大用户基数

#### 4. OpenAI Codex CLI
- **类型**: CLI（Rust 构建，开源）
- **模型**: GPT-5.4（SWE-Bench Pro 57.7%）
- **定价**: CLI 免费，需 ChatGPT 订阅 $20-200
- **杀手锏**: 高性能，子代理并行，GPT-5.4 原生电脑操作
- **定位**: CLI 领域 Claude Code 的最直接对手

#### 5. Devin (Cognition Labs)
- **类型**: 全自主 AI 工程师 + Windsurf IDE
- **模型**: 自研 SWE-1.5 / SWE-grep
- **定价**: Core $20/月 + $2.25/ACU，Team $500/月
- **杀手锏**: 最接近"自主 AI 工程师"，虚拟机隔离，多实例并行
- **规模**: 估值 $102亿

---

### 第二梯队：特定场景有竞争力

#### 6. Google Gemini 生态
- **Gemini CLI**: 2026.3 发布，Apache 2.0 开源，**免费用 Gemini 2.5 Pro + 1M 上下文**
- **Jules**: 异步后台代理，免费 15次/天
- **Code Assist**: VS Code / JetBrains / Android Studio
- **优势**: 免费额度极高，Android 开发最强

#### 7. Windsurf (原 Codeium → Cognition)
- **定价**: Free / Pro $15 / Teams $30
- **杀手锏**: Cascade 代理式 AI，与 Devin 深度集成
- **风险**: 被收购后核心团队流失到 Google

#### 8. Kiro (AWS)
- **定价**: Free / Pro $20 / Power $200
- **杀手锏**: Spec-driven Development（需求→设计→任务自动分解），AWS GovCloud 支持
- **适合**: 合规要求高的企业、政府项目

#### 9. JetBrains AI + Junie
- **定价**: Free / Pro $8 / Ultimate $30
- **杀手锏**: JetBrains IDE 原生体验，Junie 自主代理
- **适合**: Java/Kotlin 开发者

#### 10. Augment Code
- **定价**: Indie $20 / Standard $60 / Max $200
- **杀手锏**: Context Engine 索引 10万+ 文件，跨多仓库理解
- **适合**: 大规模企业代码库

#### 11. Amazon Q Developer
- **定价**: Free / Pro $19/用户
- **杀手锏**: 深度 AWS 集成，自主代理，成本诊断
- **适合**: AWS 重度用户

### 第三梯队：开源 / 性价比

#### 12. Cline (VS Code 扩展，开源)
- **GitHub Stars**: 58K+
- **定价**: 免费（BYO-Key）
- **杀手锏**: 人机协作每步审批，完全开源，无供应商锁定

#### 13. OpenCode (开源 CLI)
- **GitHub Stars**: 120K
- **月活**: 500万开发者
- **杀手锏**: Go 构建，配合 DeepSeek API **月费仅 $2-5**，性价比之王

#### 14. Aider (开源 CLI)
- **定价**: 免费（BYO-Key）
- **杀手锏**: 经典终端 AI 结对编程，支持 100+ 模型
- **地位**: CC 出现前的 CLI 标杆

#### 15. Continue.dev (开源)
- **定价**: Solo 免费 / Team $10/人
- **杀手锏**: VS Code + JetBrains 双平台，CI 集成，企业友好

#### 16. Trae (字节跳动)
- **定价**: **免费提供** Claude 4 Sonnet / GPT-4o / DeepSeek R1
- **杀手锏**: 免费层极其慷慨
- **风险**: 数据隐私担忧

#### 17. Zed AI
- **定价**: Free / Pro $10
- **杀手锏**: Rust 编写极速编辑器（120fps），多模型并行生成
